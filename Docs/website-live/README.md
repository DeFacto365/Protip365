# www.protip365.com (live site source)

Deployed to production on 2026-10-02 with the Vercel CLI (`vercel deploy --prod` from this folder).
The project is not built from the repo root, so deploy this folder directly. Pushing to `main` alone does not update the site correctly.

- `index.html` + `landing.css`: landing page that shows the 12 screens one by one
- `prototype.html` + `app.js` + `style.css`: interactive demo with sample data
- `privacy/`, `terms/`, `support/`: legal and support pages (unchanged)
