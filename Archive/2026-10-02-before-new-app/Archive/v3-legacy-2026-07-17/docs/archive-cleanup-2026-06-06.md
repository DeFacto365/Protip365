- `ProTip365Shared/` is the shared Expo/React Native app for iOS and Android.

- `Archive/legacy-native/ProTip365Android/` contains the legacy native Android app.
- `Archive/docs/legacy-root-docs/` contains old native implementation docs, screenshots, setup notes, and previous validation notes.
- `Archive/docs/legacy-website-material/` contains unused website templates, demo assets, WordPress exports, and older landing page variants.
- `Archive/tools/browser-tools-mcp-reference.md` records the old browser tooling checkout reference.

## Sync policy

This archive state was intended to be synced once to GitHub for preservation. After that, active work should happen outside `Archive/`; future changes under `Archive/` should be treated as reference-only unless explicitly requested.
